# Seraphim Desk · v-next

One offline HTML file: `vnext.html` (the build that produced it named its output `seraphim-desk-vnext.html`; that build file is not in this repo). It sorts any data dump through the Seraphim × Headroom seal. Each item either **crystallizes** (inside the seal) or is **released** (held outside it). Nothing is uploaded, and the page makes a single request when it loads.

## The gate is the real gate
- `SG` is described by the build as a line-for-line JS port of `residual_gates_numpy.py` (the Python twin; not included in this repo): gate_b, gate_a, admit, mask_of, crew_bound, Word128 checked_add / accrue_vec, may_dispatch, job_admit. It uses BigInt integers, wraps int64 the way NumPy does, and raises the way NumPy does on inputs that overflow int64.
- Desk rule: a line crystallizes only if it passes the canon content classifier AND `C + R ≤ I(t)` holds on every axis (gate_b over I, accrued with Word128 checked_add, plus job_admit). Anything else is released. Any error, invalid claim, overflow or failed parity refuses. The seal fails closed.
- Constants come from the SERAPHIM DESK Controller (commit 8fa6f61): I = (120, 120, 100, 100) for compute/memory/power/thermal, and the seal drains C × 65/100 every 40 lines. Claims are integerized at 1/1000 and always rounded up.
- On load the page checks its own port: it runs 38 self_test asserts ported from the twin plus 350 fixtures that are embedded in the page (generated by the Python twin, per the build). If any of them fails, nothing crystallizes. This in-page check is the part you can reproduce from this repo: open `vnext.html` and read the parity badge.

## Parity (reported by the build, 2026-09-27)
These results were reported by the build that produced `vnext.html`. The reproduction scripts (`parity/parity_node.js`, `parity/replay_desk.py`, `parity/classifier_equiv.js`) and the Python twin are **not included in this repo**, so these numbers can't be re-run from here.
- Reported for `parity/parity_node.js`: 38/38 self_test and 20,000/20,000 twin-generated fixtures, run against the code shipped in the page.
- Reported for `parity/replay_desk.py`: the Python twin replayed whole desk runs step by step (13 steps (bundle), 20,000 lines and 100,000 lines) with 0 mismatches and a matching final C.
- Reported for `parity/classifier_equiv.js`: the scale accelerator gave the same answers as the canon classifier (0eafbeb) on 50,756 lines (0 differences), and the canon test-classifier passed 124/124 with and without the accelerator.
- What this repo can check: `vnext.html` embeds the canon content classifier byte-for-byte (the same `SERAPHIM_NOTE_CLASSIFIER` block as `index.html`), and `seraphim-work/test-classifier.js` passes 124/124 against `vnext.html`.

## Evolve features
- Drag-and-drop anywhere on the page: .csv .tsv .json .jsonl .txt .md, several files at once. Other file types are skipped and listed.
- **Export crystallized bundle** (.zip, built in the page): manifest.json, crystallized.json/.csv/.md, release-ledger.csv, gate-trace.csv (the build says it can be replayed with `replay_desk.py`, which is not included in this repo) and README.txt.
- Session history in localStorage (up to 20 sessions). The last session restores itself after a reload. ↺ re-runs a session and × forgets it.
- Scale mode above 5,000 items: work runs in 40 ms chunks with a progress bar, the page keeps painting, trays show at most 400 chips each (the export has every item), and the input cap is 250,000 lines. In headless software-GL QA, 20k lines took 2.3 s and 100k took 14.4 s.
