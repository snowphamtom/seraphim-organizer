# Seraphim Desk · v-next

One offline HTML file: `vnext.html` (the build output is `seraphim-desk-vnext.html`). It sorts any data dump through the Seraphim × Headroom seal. Each item either **crystallizes** (inside the seal) or is **released** (held outside it). Nothing is uploaded, and the page makes a single request when it loads.

## The gate is the real gate
- `SG` is a line-for-line JS port of `residual_gates_numpy.py`: gate_b, gate_a, admit, mask_of, crew_bound, Word128 checked_add / accrue_vec, may_dispatch, job_admit. It uses BigInt integers, wraps int64 the way NumPy does, and raises the way NumPy does on inputs that overflow int64.
- Desk rule: a line crystallizes only if it passes the canon content classifier AND `C + R ≤ I(t)` holds on every axis (gate_b over I, accrued with Word128 checked_add, plus job_admit). Anything else is released. Any error, invalid claim, overflow or failed parity refuses. The seal fails closed.
- Constants come from the SERAPHIM DESK Controller (commit 8fa6f61): I = (120, 120, 100, 100) for compute/memory/power/thermal, and the seal drains C × 65/100 every 40 lines. Claims are integerized at 1/1000 and always rounded up.
- On load the page proves its own port: it runs the twin's 38 self_test asserts plus 350 fixtures generated by the Python twin. If any of them fails, nothing crystallizes.

## Parity (run 2026-09-27)
- `parity/parity_node.js`: 38/38 self_test, 20,000/20,000 twin-generated fixtures, run against the exact code shipped in the page.
- `parity/replay_desk.py`: the Python twin replays whole desk runs step by step: 13 steps (bundle), 20,000 and 100,000 lines. There were 0 mismatches and the final C matched.
- `parity/classifier_equiv.js`: the scale accelerator returns the same answers as the canon classifier (0eafbeb) on 50,756 lines (0 differences). The canon test-classifier passes 124/124 both with and without the accelerator.

## Evolve features
- Drag-and-drop anywhere on the page: .csv .tsv .json .jsonl .txt .md, several files at once. Other file types are skipped and listed.
- **Export crystallized bundle** (.zip, built in the page): manifest.json, crystallized.json/.csv/.md, release-ledger.csv, gate-trace.csv (replayable with `replay_desk.py`) and README.txt.
- Session history in localStorage (up to 20 sessions). The last session restores itself after a reload. ↺ re-runs a session and × forgets it.
- Scale mode above 5,000 items: work runs in 40 ms chunks with a progress bar, the page keeps painting, trays show at most 400 chips each (the export has every item), and the input cap is 250,000 lines. In headless software-GL QA, 20k lines took 2.3 s and 100k took 14.4 s.
