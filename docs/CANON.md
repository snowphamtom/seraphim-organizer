> **2026-09-27 classifier hardening (polish only; hero and input unchanged):** Duplicates are checked before the spam rules and are case-insensitive, so an UPPERCASE copy of an earlier line goes to ASIDE instead of tripping the all-caps rule. Only kept lines (and their duplicates) are remembered, so a refused or noise line never turns a later original into a "duplicate", and repeated spam or mash stays REFUSE or NOISE. New conservative spam rules cover dating spam (hot/local singles) and phishing ("your account has been suspended", "verify/confirm your password/account/identity", unusual sign-in activity, undelivered package, "update your payment details", password expiry). Each phishing phrase is only a hint on its own; two together, or one plus another signal, refuse. Letters in any script (\p{L}: Cyrillic, CJK, Arabic, accented) count as real text, and no-space scripts count as more than one word, so non-English is no longer NOISE/empty. The keyboard-mash heuristics still apply to Latin text. `!!!`, `!!`, `$$` and 🚀💰🤑💸🔥🔥 are now amplifiers: they only add to a line that already has a real spam signal, so they no longer send a normal post to REFUSE or HOLD on their own. Regression cases in `seraphim-work/test-classifier.js` (73/73); browser checks 53/53. Proof: `/workspace/proof/REPORT-v2.md`.
