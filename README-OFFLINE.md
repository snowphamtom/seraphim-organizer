# Seraphim Organizer — Offline

Works with **no Grok Bot**, **no Cursor**, **no internet** after you save the file.

## Use
1. Open `standalone.html` in Chrome / Safari / Firefox (double-click).
2. Drop a CSV / JSON / TXT dump (or paste).
3. Click **Organize** — crystallize / vaporize under `S_H = S_solv · R_H`.
4. Download JSON or CSV results.
